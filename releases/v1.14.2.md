# atc-web production suite 1.14.2

Release date: 2026-10-14

All 15 repositories at `v1.14.2`. The installer descriptor is
[`../installation-manifests/v1.14.2.json`](../installation-manifests/v1.14.2.json), selected by
[`../installation-manifests/supported.json`](../installation-manifests/supported.json).

## Changes

- **atc-notify sends email only.** The webhook channel is removed together with
  `WEBHOOK_SIGNING_SECRET`, `WEBHOOK_ALLOWED_HOSTS`, `WEBHOOK_ALLOW_HTTP`, `WEBHOOK_TIMEOUT_MS`,
  `NOTIFY_WEBHOOK_CHANNEL` and the `WEBHOOK_CHANNEL_DISABLED` error. `POST /v1/messages` accepts
  only `channel: "email"`; messages no longer carry `event` or `url`, and `template`/`to` are always
  set. `/v1/info` capabilities are `email`, `templates`, `idempotency`. The shutdown ceiling follows
  the SMTP worst case, so PM2 `kill_timeout` is 80 s. Outbound webhooks are the job of
  `atc-webhook-out`. The Console notify pages and the `atc-notify.messages.create` MCP tool follow.
- **Console navigation:** below 900 px the sidebar becomes an off-canvas drawer opened from the
  header; the signed-in user and sign-out sit at the bottom of the sidebar at every width. The
  mobile bottom bar is gone.
- **Console cleanup:** the service worker owns only its own `atc-console-static-` caches; TOTP
  secrets must carry a key id; unused interface strings are removed.
- **Repository cleanup:** superseded planning and audit documents, old installation manifests and
  old release notes are removed from `atc-stack`; Git history and tags keep them. `PROJECT_STATE.md`
  describes only the current state.
