# atc-web production suite 1.15.0

Release date: 2026-10-14

All 15 repositories at `v1.15.0`. The installer descriptor is
[`../installation-manifests/v1.15.0.json`](../installation-manifests/v1.15.0.json), selected by
[`../installation-manifests/supported.json`](../installation-manifests/supported.json).

## Changes

- **Console runs on SvelteKit 3** (`@sveltejs/kit` 3.0.1, `@sveltejs/adapter-node` 6.0.0, Svelte
  5.57.2, Vite 8.3.4). Configuration moved from `svelte.config.js` into `vite.config.ts`; `$lib`
  imports became `#lib` subpath imports; the service worker reads `$app/env` and `$app/manifest`.
  SvelteKit's version polling is off (`version.pollInterval: 0`), so the service worker stays the
  only update check. The low-severity development `cookie` advisory is gone.
- **Console CSRF:** SvelteKit 3 would reject body-less mutations whose `Origin` does not match
  (non-browser clients, TLS-terminating proxies). Its origin check is disabled because every API
  mutation already requires the `X-Console-Request` header. Login and TOTP accept a request without
  that header only with `Content-Type: application/json`, which a cross-site form cannot send.
- **Node 22.17+** is required (SvelteKit 3 minimum); `stack install:all` checks it before
  installing.
- **Console browser smoke** fails on any uncaught page exception and covers the service-worker
  update prompt: a waiting worker shows exactly one prompt, the page keeps rendering, and Reload
  activates the new worker.
