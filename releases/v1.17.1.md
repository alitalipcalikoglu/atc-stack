# atc-web production suite 1.17.1

Release date: 2026-10-14

All 15 repositories at `v1.17.1`. The installer descriptor is
[`../installation-manifests/v1.17.1.json`](../installation-manifests/v1.17.1.json), selected by
[`../installation-manifests/supported.json`](../installation-manifests/supported.json).

## Changes

- **Console overview cards:** icon, name, address and status on top; headline numbers as two-column
  tiles; latency, uptime, last refresh, the auto-refresh countdown and the refresh button in a
  footer. The countdown has a fixed width, so cards and buttons no longer move while it ticks, and
  footers line up across a row.
- **Scrollbars:** thin, theme-coloured and always visible; the page always reserves the scrollbar
  gutter, so the layout width no longer changes between short and long pages.
- **Table scroll fade:** the right-edge fade on scrolling tables (and mobile segmented controls) shows
  only while content is hidden to the right; a table that fits, or one scrolled to its end, shows
  none.
