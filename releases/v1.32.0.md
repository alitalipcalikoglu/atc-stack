# atc-web production suite 1.32.0

Release date: 2026-10-16

All 22 repositories at `v1.32.0`: 20 HTTP services, `atc-service-core` and `atc-stack`. The installer
descriptor is [`../installation-manifests/v1.32.0.json`](../installation-manifests/v1.32.0.json),
selected by [`../installation-manifests/supported.json`](../installation-manifests/supported.json).

## Security review fixes

A code review of the whole workspace found 4 medium and 8 low findings; every one is fixed here,
each with a test.

- **atc-flags:** a new flag starts disabled in a protected environment; archive, reshuffle and
  delete go through the two-person rule as a `flag` change request (`202`). `ACTOR_KEYS` keys must
  send `X-Actor` on every write (`400 ACTOR_REQUIRED`); approval compares people, not keys.
- **atc-auth:** MFA setup, enable and recovery-code rotation require the current password; wrong
  passwords and codes count toward the lockout. Every auth mail is sent as transactional.
- **atc-notify:** `transactional: true` messages bypass unsubscribe and complaint suppressions but
  still respect bounces and operator suppressions (readwrite/admin keys only).
- **atc-status:** one confirmation mail per address per ten minutes; the quota counts confirmed
  subscribers only; unconfirmed sign-ups are pruned after two hours.
- **atc-console:** a TOTP code used in one step cannot disable two-factor in another; behind a
  trusted proxy the client IP is the last `X-Forwarded-For` hop.
- **atc-media:** file restore keeps no replay store, so signed URLs are never stored.
- **atc-payments:** the client secret never enters the idempotency store.
- **atc-backup:** standby downloads stop at the recorded size and after 30 minutes.
- **atc-export:** notify recipients and suppressions are `personal: true` sources exported only by
  the new export `admin` role.
- **atc-render:** cancelling a job requires the write role.

## Console

- Render jobs (list, detail, PDF download, cancel), queue-render dialog and fonts panel; shortlink
  batch create; the rate-limit page shows the active counter backend.
- Global search also matches names in the scoped services (flag keys, jobs, subscriptions, indexes,
  queues, namespaces, policies, monitors), grouped by service.
- List pages no longer debounce their first load: scheduler and webhooks open in about 40 ms
  instead of 350 ms.

## Breaking changes

- flags `changes` table rebuilt; render migration adds the `cancelled` status.
- Export of notify sources needs an export key with the `admin` role.
