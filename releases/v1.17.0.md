# atc-web production suite 1.17.0

Release date: 2026-10-14

All 15 repositories at `v1.17.0`. The installer descriptor is
[`../installation-manifests/v1.17.0.json`](../installation-manifests/v1.17.0.json), selected by
[`../installation-manifests/supported.json`](../installation-manifests/supported.json).

## Changes

- **Console administrators sign in with a username.** Admin accounts no longer carry an email.
  Database migration 3 renames `admins.email` to `username` and `audit.admin_email` to
  `admin_username`; an existing account keeps the part before `@` (or the whole address with `@`
  replaced by `.` when two accounts would clash), so `admin@console.local` becomes `admin`.
  The login body is `{ username, password }`, admin creation takes `username`
  (`^[a-z0-9][a-z0-9._-]{0,63}$` after trimming and lowercasing; `USERNAME_TAKEN` on a clash), the
  admin list, account page, TOTP label, console log (`adminUsername`) and `npm run admin` CLI follow.
- **No password strength rules for console administrators:** a password must only be non-empty and
  at most 256 characters. Enable TOTP for every administrator on a reachable host; the console holds
  every service key.
- **Stack:** `setup`/`install:all` take `--admin-username` (default `admin`) instead of
  `--admin-email`. The first-admin check now counts every existing account, so a stack whose admin
  has another name never gets a second one.
- Media byte ranges were checked against a running media service: single, open-ended and suffix
  ranges answer `206` with exact bytes, an out-of-file range `416`, multi-range and other units the
  whole file.
