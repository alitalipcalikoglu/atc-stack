# atc-web production suite 1.20.0

Release date: 2026-10-14

All 22 repositories at `v1.20.0`: 20 HTTP services, `atc-service-core` and `atc-stack`. The installer
descriptor is [`../installation-manifests/v1.20.0.json`](../installation-manifests/v1.20.0.json),
selected by [`../installation-manifests/supported.json`](../installation-manifests/supported.json).

## MCP server

- **153 tools** (from 10): read tools for every service plus safe writes such as create, update,
  enqueue, publish, start an export, render a stored document, create a monitor or a payment
  intent. Nothing destructive or irreversible is exposed: no delete, purge, refund, cancel, restore,
  revoke, rotate or key and role change, and nothing that re-sends mail or webhook deliveries.
- **atc-auth** is read-only with secret fields filtered from every result; **atc-console** answers
  only the status probe. Webhook subscription results never include the signing secret.
- **Policy:** `mcp/tool-policy.mjs` lists the exposed operations per service and gives a reason for
  every excluded write class. `npm run mcp:catalog` regenerates the tool files and the catalog,
  and fails when policy, tools and catalog disagree.
- Payment intents require an idempotency key; rendered documents are stored in atc-media and
  returned by reference; export downloads return a signed URL.

## Stack

- `npm run setup` issues a dedicated `atc-mcp` key on every service with tools, with the smallest
  role that covers them, and writes `mcp.env` and `.mcp.json` (owner-only, ignored by Git) for MCP
  clients such as Claude Code and Claude Desktop.
- `npm run mcp:config [--read-only|--full] [--print]` regenerates the keys and both files.

## Fixes

- **atc-service-core:** a pre-migration backup that a concurrent process's migration overtook is
  dropped instead of being kept under a wrong version name.
